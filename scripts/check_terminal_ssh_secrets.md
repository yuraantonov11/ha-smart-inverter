# Home Assistant «Insecure secrets detected» для Terminal & SSH

Це попередження стосується секрету, який Home Assistant розпізнав як відомий у витоках. Home Assistant перевіряє його через Have I Been Pwned із застосуванням k-anonymity: надсилається лише префікс хешу, а повний секрет не передається. Сприймайте попередження серйозно й замініть секрет, який воно позначило. Воно саме по собі не доводить, що хтось увійшов до вашої системи.

Джерела: [Home Assistant: Pwned passwords and secrets](https://www.home-assistant.io/more-info/pwned-passwords), [офіційна схема Terminal & SSH](https://github.com/home-assistant/addons/blob/master/ssh/config.yaml), [документація Terminal & SSH](https://github.com/home-assistant/addons/blob/master/ssh/DOCS.md).

## Перевірте саме додаток

У Home Assistant відкрийте **Settings → Apps → Terminal & SSH → Configuration**. Перевірте локально, чи ввімкнений парольний вхід або налаштовані `authorized_keys`. Не копіюйте пароль, ключ чи повний JSON у чат або журнали. Офіційна схема поточного додатка містить `password`, `authorized_keys`, `apks` і `server.tcp_forwarding`; точний набір залежить від встановленої версії. Не додавайте поля `password_hash`, `ssh_keys`, `username` або інші поля, яких немає в схемі саме вашої версії.

## Замініть пароль без втрати доступу

Якщо використовуєте парольний SSH-вхід, змініть його в конфігурації **Terminal & SSH** на новий, унікальний пароль і збережіть зміни. Якщо переходите на SSH-ключі, спочатку додайте public key, перезапустіть додаток і перевірте нове підключення окремим терміналом. Лише після успішної перевірки вирішуйте, чи вимикати парольний вхід. Документація додатка зазначає, що парольний та ключовий варіанти входу не працюють одночасно.

`ha auth reset` змінює обліковий запис Home Assistant; це не команда зміни пароля додатка Terminal & SSH. Не використовуйте її для цього попередження. Не видаляйте чинні ключі, не змінюйте мережевий порт і не відкривайте SSH назовні, щоб усунути попередження.

Після заміни позначеного секрету перевірте в Supervisor, що попередження більше не відображається. Перевірка конфігурації додатка лише підтверджує відповідність його схемі; вона не є підтвердженням, що секрет прибрано зі списку відомих витоків. Якщо повідомлення лишилося, відкрийте його деталі в Supervisor і перевірте, який саме секрет він позначає, не розкриваючи його значення.
